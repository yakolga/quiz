# Quiz Project

This project is a quiz application designed to test knowledge on various topics. The application is structured to provide an engaging and interactive experience for users.

## Features

- Multiple-choice questions
- Scoring system to track progress
- Timer for each question (optional)
- User-friendly interface

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yakolga/construction-calculator.git
    ```
2. Navigate to the project directory:
    ```bash
    cd quiz
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

1. Start the application:
    ```bash
    npm start
    ```
2. Open your browser and navigate to `http://localhost:3000`.

## Folder Structure

- `/src`: Contains the source code for the application.
- `/public`: Static files and assets.
